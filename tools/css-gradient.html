💡使用说明
本工具是一款免费的 CSS 渐变与盒阴影生成器，帮助前端开发者和设计师快速生成兼容现代浏览器的 CSS 代码。渐变生成器支持线性渐变和径向渐变两种类型，您可以添加多个色标并调整它们的位置，实时预览效果并复制生成的 CSS 代码。盒阴影生成器则通过可视化的滑块调整偏移、模糊、扩展和颜色参数，实时预览阴影效果。所有生成的 CSS 代码均使用标准语法，兼容 Chrome、Firefox、Safari、Edge 等主流浏览器。使用方式非常简单：调节各参数滑块和色标，预览区域会实时更新，满意后点击「复制 CSS」即可将代码粘贴到您的样式表中。
❓常见问题

Q1: 生成的 CSS 兼容旧版浏览器吗？

生成的 CSS 使用标准语法，兼容所有现代浏览器（Chrome、Firefox、Safari、Edge）。IE11 及以下版本不支持 CSS 渐变，但已极少使用。

Q2: 可以添加多少个色标？

理论上没有限制，但建议控制在 5-7 个以内以保证性能和视觉效果。

Q3: 径向渐变的中心点可以调整吗？

当前版本使用默认中心点（center）。如需更复杂的径向渐变（如椭圆、指定中心位置），可在生成的基础代码上手动修改 CSS 属性。

Q4: 盒阴影支持内阴影吗？

当前版本生成的是外阴影。如需内阴影（inset），可在复制的 CSS 代码中的 box-shadow 值前手动添加 inset 关键字。

Q5: 颜色格式支持哪些？

色标使用浏览器原生颜色选择器，输出格式为 HEX（如 #3a7bd5）。如需 RGBA 或其他格式，可在复制后手动转换。
