💡使用说明
本工具是一款完全在浏览器本地运行的图片压缩与格式转换器，无需上传图片到服务器，充分保护您的隐私。它适用于网站管理员优化网页加载速度、开发者压缩应用图标与截图、设计师快速导出不同格式素材等多种场景。使用步骤非常简单：首先点击「选择图片」按钮，从本地设备中选取一张图片（支持 JPG、PNG、GIF、WebP 等常见格式）；然后在输出格式下拉菜单中选择目标格式（JPEG 适合照片、PNG 适合透明图标、WebP 兼顾体积与质量）；接着拖动质量滑块调节压缩比例，数值越低体积越小但画质损失越大；最后点击「压缩并预览」即可实时查看压缩前后的对比效果，满意后点击「下载结果」保存到本地。整个处理过程基于 HTML5 Canvas API 在本地完成，图片数据不会离开您的设备。
❓常见问题

Q1: 压缩后的图片会保存到服务器吗？

不会。本工具完全在您的浏览器本地运行，所有处理通过 HTML5 Canvas 完成，图片数据不会上传或发送到任何外部服务器。

Q2: 支持哪些图片格式？

支持读取 JPG、PNG、GIF、WebP、BMP 等浏览器可解码的格式；输出支持 JPEG、PNG 和 WebP 三种格式。

Q3: WebP 格式有什么优势？

WebP 在相同视觉质量下通常比 JPEG 小 25%-35%，比 PNG 小 26%，同时支持有损和无损压缩以及透明度，是现代网页优化的首选格式。

Q4: 压缩后图片尺寸会改变吗？

图片的宽度和高度保持不变，仅通过调整编码质量和格式来减小文件体积。如需调整尺寸，请先用图片编辑工具裁剪或缩放。

Q5: 为什么 PNG 输出时质量滑块无效？

PNG 是无损压缩格式，浏览器 Canvas API 在导出 PNG 时不支持质量参数。如需减小 PNG 体积，建议转换为 WebP 格式。
