💡使用说明

  

    本工具将图片文件转换为 Base64 编码的 Data URI 格式，适用于需要将图片直接嵌入 HTML/CSS 代码中的场景，如单文件 HTML 邮件、离线文档、减少 HTTP 请求数等。使用方式非常简单：点击「选择图片」按钮，从本地设备选取一张图片，工具会立即通过浏览器原生的 FileReader API 读取文件并转换为 Base64 字符串。转换完成后，您可以看到原始文件大小、Base64 编码后的大小以及膨胀率（Base64 通常比原始文件大约 33%）。同时，工具会生成两种常见的使用示例代码：CSS background-image 属性和 HTML img 标签的 src 属性，方便您直接复制粘贴到项目中。请注意，由于 Base64 编码会增加文件体积，建议仅对小型图片（如图标、小logo，建议小于 50KB）使用此技术，大图片会影响页面加载性能。所有处理均在浏览器本地完成，图片不会上传到任何服务器。
  






  
❓常见问题

  

    
Q1: Base64 图片比原图大多少？

    
Base64 编码通常会使文件体积增加约 33%。这是因为每 3 字节的二进制数据被编码为 4 字节的 ASCII 字符。

  

  

    
Q2: 可以转换 SVG 文件吗？

    
可以。SVG 文件同样可以转换为 Base64 Data URI。但对于 SVG，更推荐直接以内联 SVG 代码的方式嵌入页面，因为这样可以保持矢量特性且体积更小。

  

  

    
Q3: Data URI 有大小限制吗？

    
不同浏览器对 Data URI 的长度限制不同，通常在几 MB 范围内。但出于性能考虑，建议仅对小于 50KB 的图片使用 Base64 嵌入，大图片应使用常规 URL 引用。

  

  

    
Q4: 图片会被上传到服务器吗？

    
绝对不会。所有转换通过浏览器原生的 FileReader API 在本地完成，图片数据不会离开您的设备。

  

  

    
Q5: 转换后的 Data URI 可以在所有浏览器中使用吗？

    
Data URI 已被所有现代浏览器广泛支持，包括 Chrome、Firefox、Safari、Edge 以及移动端浏览器。IE8 及以下版本不支持，但已极少使用。
