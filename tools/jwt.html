💡使用说明

  

    本工具是一款安全的 JWT（JSON Web Token）解码器，完全在浏览器本地运行，不会将您的 Token 发送到任何服务器。JWT 是现代 Web 应用中最常用的身份验证和信息传递格式，由 Header、Payload 和 Signature 三部分组成，各部分以点号分隔。本工具可以将这三部分分别解码并友好地展示 JSON 内容，同时自动识别并格式化 exp（过期时间）、iat（签发时间）等常用声明字段。需要特别注意的是，本工具仅提供解码展示功能，不会、也不能验证签名的真实性——验证签名需要服务端持有的密钥。因此，请勿将本工具的解码结果作为身份验证依据。适用场景包括：调试 API 时快速查看 Token 内容、学习 JWT 结构、排查 Token 过期问题等。只需将 Token 粘贴到输入框中，点击「解码」即可。
  






  
❓常见问题

  

    
Q1: 这个工具会验证 JWT 签名吗？

    
不会。本工具仅解码 Base64URL 编码的内容并展示 JSON，不进行任何签名验证。验证签名需要服务端私钥或密钥，在线工具无法安全地完成此操作。

  

  

    
Q2: 我的 JWT Token 会被发送到服务器吗？

    
绝对不会。所有解码运算都在您的浏览器本地通过 JavaScript 完成，Token 内容不会离开您的设备。

  

  

    
Q3: 为什么解码后的 exp 显示的是日期？

    
exp 和 iat 字段的值是 Unix 时间戳（秒）。本工具会自动将其转换为人类可读的本地日期时间，并在 Token 已过期时给出醒目提示。

  

  

    
Q4: 支持哪些 JWT 算法？

    
由于本工具仅解码不验签，因此支持所有算法的 JWT Token，包括 HS256、HS384、HS512、RS256、ES256 等。解码结果会显示算法名称但不验证其有效性。

  

  

    
Q5: 输入格式不对怎么办？

    
标准的 JWT 由三部分组成，用两个点号分隔（xxxxx.yyyyy.zzzzz）。如果输入不符合此格式，工具会提示错误并给出说明。
