# 009tg导航站 - Web管理后台

本地Web界面，用于导航站的数据管理：抓取新站点、分类映射、重复检测、合并生成、搜索删除。

## 功能特性

| 模块 | 功能 |
|------|------|
| **仪表盘** | 数据统计（站点数/分类数）、快捷操作、分类排行 |
| **抓取站点** | 通用抓取（任意导航站URL）+ 指定脚本抓取（4个已有源站） |
| **合并生成** | 分类映射（自动+手动）、重复检测、一键合并+生成所有页面 |
| **数据管理** | 按关键词/分类搜索站点、删除失效站点 |

## 快速开始

### 1. 安装依赖

```bash
pip install flask requests beautifulsoup4 pillow pyyaml
```

### 2. 启动

**方式一：双击启动（推荐）**

双击项目根目录下的 `启动Web管理后台.bat`，会自动启动服务并打开浏览器。

**方式二：命令行启动**

```bash
# 在项目根目录执行
python tools/web_admin/app.py
```

启动后访问：http://127.0.0.1:5000

## 使用流程

### 抓取新站点完整流程

```
① 抓取站点 → ② 分类映射 → ③ 重复检测 → ④ 合并生成 → ⑤ 手动git部署
```

#### 步骤1：抓取站点

1. 点击左侧菜单"抓取站点"
2. 选择抓取方式：
   - **通用抓取**：输入任意导航站URL，自动识别结构
   - **指定脚本抓取**：选择已有的针对特定站点的脚本（数据更准确）
3. 点击"开始抓取"，等待完成（1-5分钟）
4. 抓取完成后显示分类数和站点数

#### 步骤2：分类映射

1. 抓取完成后点击"下一步：分类映射与合并"
2. 为每个抓取到的分类选择目标分类（下拉框）
   - 可以点击"自动映射"自动匹配同名分类
   - 未映射的分类将被跳过
3. 可以勾选/取消勾选分类来决定是否导入

#### 步骤3：重复检测

1. 系统自动按域名检测重复站点
2. 默认勾选"跳过重复站点"
3. 如需覆盖已有站点，取消勾选即可

#### 步骤4：合并生成

1. 点击"开始合并生成"
2. 系统自动执行：
   - 合并数据到 `完整版导航.json`
   - 下载新站点的favicon
   - 生成中英文首页
   - 生成分类详情页（210个）
   - 更新sitemap
3. 实时显示执行日志
4. 完成后显示统计（新增/重复/跳过）

#### 步骤5：手动部署

生成完成后，需要手动提交git部署：

```bash
git add .
git commit -m "抓取新增站点"
git push origin master
```

Cloudflare会在1-2分钟内自动部署。

### 删除失效站点

1. 点击左侧菜单"数据管理"
2. 输入关键词（站点名/URL/描述）或选择分类
3. 点击"搜索"
4. 在结果中找到要删除的站点，点击"删除"
5. 确认删除
6. 删除后需要重新生成所有页面并提交部署

## 常见问题

### Q: 启动报错 "ModuleNotFoundError: No module named 'flask'"

A: 安装Flask：`pip install flask`

### Q: 通用抓取找不到站点怎么办？

A: 通用抓取适用于结构标准的导航站。如果目标站点结构特殊：
1. 检查页面是否为纯JS渲染（查看源代码是否有工具内容）
2. 如为纯JS渲染，尝试用浏览器开发者工具分析API
3. 编写专用抓取脚本（参考 `tools/crawler/` 下的现有脚本）

### Q: 抓取速度很慢怎么办？

A: 抓取速度取决于目标站点响应速度。可以：
1. 检查网络连接
2. 国外站点可能需要代理
3. 对于已有专用脚本的站点，使用指定脚本抓取更快

### Q: 分类映射找不到目标分类怎么办？

A: 可以：
1. 先在 `完整版导航.json` 中手动添加新分类
2. 或者映射到相近的现有分类，后续再调整
3. 未映射的分类会被跳过，不会导入

### Q: 合并后网站没有变化怎么办？

A: 检查：
1. 是否重新生成了所有页面（合并时会自动生成）
2. 是否提交了git（`git add . && git commit && git push`）
3. Cloudflare是否部署完成（1-2分钟）
4. 浏览器是否强制刷新（Ctrl+F5）

### Q: 误删了站点怎么办？

A: 如果还没提交git，可以用 `git checkout -- 完整版导航.json` 恢复。如果已提交，从git历史中恢复：
```bash
git log --oneline 完整版导航.json
git checkout <commit_id> -- 完整版导航.json
```

### Q: 数据文件太大打不开怎么办？

A: `完整版导航.json` 约2MB，建议用VS Code或Notepad++打开，不要用记事本。

## 注意事项

1. **数据备份**：合并操作会修改 `完整版导航.json`，建议定期备份
2. **重复检测**：按域名去重，同一域名不同路径会被视为重复
3. **国外站点**：有效性检测时，国外站点超时不一定是失效，建议人工确认
4. **本地服务**：关闭启动窗口即停止服务，不影响已生成的文件
5. **端口占用**：默认使用5000端口，如被占用可修改 `app.py` 中的端口号
