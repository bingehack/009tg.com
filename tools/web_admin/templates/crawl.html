 抓取失败

            

            

                

                
 常见问题排查

                
    
                    
  • 连接超时：目标站点可能无法访问，或需要代理。检查网络连接后重试。
    • 
                    
  • SSL错误：目标站点证书有问题，脚本会自动跳过验证。如仍失败，手动检查。
    • 
                    
  • 未找到工具卡片：目标站点结构特殊，通用抓取无法识别。建议编写专用抓取脚本。
    • 
                    
  • 纯JS渲染：目标站点靠JS加载数据，脚本会尝试查找data.json或内联数据。如失败，需用浏览器开发者工具分析API。
    • 
                    
  • 反爬限制：目标站点有反爬机制（频率限制、验证码等）。降低请求频率或使用代理。
    • 
                    
  • 编码问题：抓取内容乱码。脚本会自动检测编码，如仍有问题，手动指定编码。
    •
