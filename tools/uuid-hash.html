💡使用说明
本工具集成了 UUID v4 批量生成器和多种哈希算法计算器，完全在浏览器本地运行，无需联网即可使用。UUID（通用唯一识别码）广泛用于数据库主键、会话标识、文件名等需要全局唯一标识的场景。哈希算法则用于数据完整性校验、密码存储、数字签名等领域。UUID 生成器支持一次性批量生成最多 100 个标准 UUID v4，可选择全小写或全大写格式，并支持一键复制。哈希计算器支持 MD5、SHA-1、SHA-256 和 SHA-512 四种算法，其中 SHA 系列使用浏览器原生 SubtleCrypto API 实现，MD5 使用纯 JavaScript 自研实现。您在输入框中输入文本时，哈希值会实时自动计算并显示。所有计算均在本地完成，数据不会上传。
❓常见问题

Q1: 生成的 UUID 会重复吗？

UUID v4 的冲突概率极低（约 10 的 -15 次方量级），在绝大多数实际应用场景中可以视为全局唯一。

Q2: SHA-256 的测试结果如何验证？

空字符串的 SHA-256 标准值为 e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855；字符串 'abc' 的 MD5 标准值为 900150983cd24fb0d6963f7d28e17f72。您可以输入这些测试向量进行验证。

Q3: MD5 还安全吗？

MD5 已不再适合用于密码存储或数字签名等安全场景，因为其存在碰撞漏洞。但它仍可用于非安全目的的数据完整性校验和文件去重。

Q4: 支持 Unicode 文本吗？

支持。所有哈希计算均以 UTF-8 编码处理输入文本，中文、日文、 emoji 等 Unicode 字符均可正确计算。

Q5: 计算过程需要联网吗？

不需要。所有算法（包括 MD5）均使用纯前端 JavaScript 实现，完全离线可用。
