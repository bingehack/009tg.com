端口检测

🔌检测目标域名
🛠使用说明与限制

浏览器无法直接创建 TCP Socket，因此本工具采用间接探测方式：

  • 通过 fetch (no-cors) 尝试连接目标端口的 HTTP/HTTPS 服务
  • 连接成功（opaque response）= 端口可能开放；连接超时/失败 = 端口可能关闭或被过滤
  • 浏览器会拦截部分非 HTTP 端口（如 21/22/25），这些端口无法通过浏览器检测

检测结果仅供参考，不代表专业级端口扫描结论。
